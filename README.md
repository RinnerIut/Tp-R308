# Tp-R308
Mes travaux pratiques en Python (R308)

## Lancer les TP

Python 3.10 ou plus est nécessaire. Aucune bibliothèque externe à installer.
Ouvrir un terminal à la racine du dépôt.

### TP1

- `python TP1/partie_a.py` : gestion des notes.
- `python TP1/partie_b.py` : nombre à deviner.
- `python TP1/partie_c.py` : fonctions du pendu.
- `python TP1/partie_d.py` : jeu du pendu.

### TP2 - Morpion

`python TP2/partie_c.py`

Jouer contre l'ordinateur en saisissant une ligne et une colonne entre 0 et 2.
Voir [TP2/README.md](TP2/README.md) pour lancer chaque partie séparément.

### TP3 - Bibliothèque

`python TP3/partie_d.py`

Le menu permet de gérer les livres, les utilisateurs et les emprunts.
Choisir **6** pour sauvegarder et quitter. Les données sont retrouvées au prochain
lancement et les fichiers CSV sont enregistrés dans `TP3/`.
Voir [TP3/README.md](TP3/README.md) pour les détails et les exemples par partie.

Les TP2 et TP3 contiennent uniquement les parties obligatoires.

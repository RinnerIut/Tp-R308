# TP2 - Morpion

Depuis la racine du dépôt, avec Python 3.10 ou plus :

- `python TP2/partie_a.py` : exemple de grille.
- `python TP2/partie_b.py` : exemple de coup aléatoire et saisie d'un coup humain.
- `python TP2/partie_c.py` : jeu complet contre l'ordinateur.

Pour jouer, entrer une ligne puis une colonne entre 0 et 2.
Les parties B et C réutilisent les fichiers des parties précédentes.
